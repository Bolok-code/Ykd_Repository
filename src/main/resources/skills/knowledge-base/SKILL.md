# 知识库管理技能

## 技能目标

帮助用户将文档存入个人知识库，并基于已存文档进行智能问答、查看和删除。

## 触发条件

当用户表达以下意图时使用本技能：

- 将文档存入资料库、保存到知识库、记住某份资料
- 对已存文档提问（"根据我的文档总结…"、"资料里提到了什么…"）
- 查看知识库中有哪些文档
- 查看某份文档的详情
- 从知识库删除文档

普通聊天、天气查询、图片生成等请求不得使用本技能。

## 必要信息

添加文档到知识库需要：

- 用户刚发送过的文件（PDF、Word、Excel、Markdown、TXT 等），且文件已被系统缓存
- 用户明确说"存入知识库""保存这份资料"等确认意图

如果用户只说"看看这份文件"，不得主动入库——必须先问清楚用户是想"查看"还是"存入"。

## 标准执行流程

### 一、文档入库

1. 用户发送文件后，必须先问清楚用户意图：是想临时查看还是长期存入知识库。
2. 只有用户明确说"存入知识库""保存""加入资料库"等确认意图后，才调用 `addDocumentToKnowledgeBase`。
3. 入库成功后告知用户：文档已保存，可以随时提问。
4. 入库失败时如实告知失败原因，并建议重试。

### 二、知识库问答

1. 用户针对已存文档提问时，调用 `answerFromKnowledgeBase`。
2. 检索到的内容会被用作回答依据。
3. 如果知识库中没有相关内容，如实告知用户。

### 三、管理知识库

- 用户说"查看知识库""有哪些文档"时，调用 `listKnowledgeBase`。
- 用户说"查看文档 X""文档 X 的详情"时，调用 `getDocumentDetail`。
- 用户说"删除文档 X""移除文档 X"时，先确认（"确定要从知识库删除 XXX 吗？"），确认后再调用 `deleteDocument`。

### 四、退出技能模式

1. 当用户说"退出知识库""退出技能""关闭知识库"，系统会自动退出技能模式回到普通对话。
2. 退出后用户可进行普通对话；用户再次表达知识库管理意图时会重新激活本技能。

## 安全规则

1. 不得在用户未明确确认的情况下擅自将文件存入知识库。
2. 删除文档前必须先向用户确认。
3. 文档内容按用户 ID 隔离，不得跨用户访问。
4. 工具返回失败时必须如实告知用户，不得虚构操作成功。

## 输出要求

每次回复应明确说明：

- 当前执行了什么操作
- 操作结果（成功/失败）
- 下一步用户可以做什么
